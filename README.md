# JavaScript Daily Work - Week 4

## Files
- `day2.js`: 10 control-flow and logic-practice problems, each with pseudocode comments before the JavaScript solution, plus a triangle challenge.
- `day3.js`: 12 functions with automated tests using Node.js `assert`, plus an extra `makeDiscount` example.

## How to run
1. Install Node.js if it is not already installed.
2. Open this folder in IntelliJ IDEA, VS Code, or a terminal.
3. Run:
   ```bash
   node day2.js
   node day3.js
   ```
4. In `day3.js`, each test should print `PASS`. The final line confirms that all tests passed.

## Note
The function list uses the class examples as guidance. The 12 tested functions are `square`, `isEven`, `celsiusToFahrenheit`, `fahrenheitToCelsius`, `formatPrice`, `getGrade`, `max`, `capitalize`, `countVowels`, `isPalindrome`, `repeatAction`, and `createCounter`. `makeDiscount` is included as an additional function-factory example.
